# genosis_aou

Version 1 was completed in R with commits directly to main to support June R01 grant submission.

### Setup

1. Open all of us analysis environment.

2. Install pre-commit on system:

```bash
pip install pre-commit

```

3. Clone and enter this repo:

```bash
git clone git@github.com:sdslack/genosis_aou.git
cd genosis_aou

```

4. Install precommit to this repo:

```bash
pre-commit install

```
